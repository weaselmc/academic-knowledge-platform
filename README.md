# Academic Knowledge Platform

A platform for extracting, normalising and managing academic information across:

- TAS
- LAP
- Assessment Plans
- Validation Records
- RTO Standards 2025
- TAC Guidance
- TIWA Policies
- Training Package Data

The platform creates a centralised academic knowledge model that can be used for:

- Compliance analysis
- Continuous improvement
- SharePoint integration
- Report generation
- AI-assisted review
- Document generation
